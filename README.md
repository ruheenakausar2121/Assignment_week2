📄 Overview

This assignment contains four Python tasks demonstrating basic programming concepts and one presentation on OOPs in Python.
Each task focuses on core logic, problem-solving, and Python syntax understanding.

⚙️ Tasks Included
🧮 1. Word Frequency Counter

File: Count_Word_Frequencies.py

This program counts how many times each word appears in a given text.

Concepts used: String manipulation, loops, and dictionaries.

Example:

Enter a text: hello world hello  
Output:  
hello : 2  
world : 1

🔁 2. Palindrome Checker

File: Palindrome_Checker.py

Checks if a word reads the same forward and backward.

Concepts used: String slicing and conditionals.

Example:

Enter a word: madam  
Output: It is a palindrome!

🔢 3. List Manipulation – Squares of Numbers

File: List_Squares.py

Creates a list of numbers and prints the square of each.

Concepts used: Lists, loops, and list comprehension.

Example:

Original List: [1, 2, 3, 4, 5]  
Squares: [1, 4, 9, 16, 25]

Real-life examples and advantages
